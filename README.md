# ATS-BreastHistopathology
Semi-Supervised Asymmetric Teacher-Student Model for Tumor Cell and Tumor Bed Segmentation in Breast Cancer

## Code and Data Availability
The ATS source code will be released in this repository. We plan to make the Real-BCD dataset available in the future, subject to institutional approval and applicable data-sharing restrictions. Updates on code release and data access will be posted here.
